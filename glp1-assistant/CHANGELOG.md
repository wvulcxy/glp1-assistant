## 🧬 导航调整

- `⚖️ 体重` Tab 改名为 `🧬 健康`，内部拆分为 3 个子页面：
  - ⚖️ 体重（身高/BMI + 体重记录 + 趋势图）
  - 📏 腰围（腰围记录 + 趋势图）
  - 🩺 指标（血脂四项 + 脂肪肝）

---

## ✨ 新增功能（共 7 项）

### 1. 📐 身高设置 + BMI 自动计算

- 入口：`🧬 健康` → `⚖️ 体重` → 顶部卡片
- 输入身高(cm)后保存
- 有体重数据时自动计算 BMI = 体重(kg) / 身高(m)²
- 显示等级：偏瘦(<18.5) · 正常(18.5~24) · 超重(24~28) · 肥胖(≥28)
- 首页统计卡片同步显示 BMI 值

### 2. 📏 腰围记录

- 入口：`🧬 健康` → `📏 腰围`
- 记录日期 + 腰围(cm)
- 折线图展示腰围变化趋势
- 汇总：起始腰围 / 当前腰围 / 已减
- 历史列表支持单条删除
- 首页统计卡片同步显示最新腰围

### 3. 🩺 健康指标追踪

- 入口：`🧬 健康` → `🩺 指标`
- 支持录入：
  - 总胆固醇 TC (mmol/L)
  - 甘油三酯 TG (mmol/L)
  - 高密度脂蛋白 HDL-C (mmol/L)
  - 低密度脂蛋白 LDL-C (mmol/L)
  - 脂肪肝等级（无/轻度/中度/重度）
- 至少填一项即可保存
- 历史卡片式展示，支持单条删除

### 4. 🔔 用药提醒通知

- 使用浏览器原生 Notification API
- 首次在注射 Tab 保存用药计划后，显示"开启通知"按钮
- 授权后，每 5 分钟检查一次
- 距离下次注射 ≤30 分钟时自动弹通知
- 通知内容：药品名 + 剂量

### 5. 📤 数据导出 CSV

- 入口：`💊 药品` Tab 底部
- 一键导出为 CSV 文件（UTF-8 BOM，Excel 直接打开不乱码）
- 导出内容：
  - 注射记录（日期/药品/剂量/部位/备注）
  - 体重记录（日期/体重）
  - 腰围记录（日期/腰围，有数据时）
  - 副作用记录（日期/症状/严重程度/备注）
  - 健康指标（日期/TC/TG/HDL/LDL/脂肪肝，有数据时）

### 6. ℹ️ 关于页面

- 入口：`💊 药品` Tab 底部
- 显示：版本号 v1.3 / 作者 wxy / 联系方式 wvulcxy@users.noreply.github.com
- 应用简介 + 免责声明

### 7. 📊 双图表增强

- 体重和腰围各有独立折线图
- 统一的图表绘制引擎（渐变填充 + 数据点标注）
- 至少 2 条记录才渲染图表
