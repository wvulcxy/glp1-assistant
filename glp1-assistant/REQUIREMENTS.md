# GLP-1 用药助手 — 需求文档 v1.3

> 更新日期：2026-06-17

## 一、项目概述

GLP-1 用药助手是一款面向 GLP-1 受体激动剂（司美格鲁肽、利拉鲁肽、替尔泊肽等）使用者的**单机版用药管理工具**。帮助用户追踪注射记录、管理用药提醒、记录体重变化和副作用，提供注射部位轮换指导。

- **平台**：Android APP（PWA 内核 + WebView 封装）
- **数据存储**：localStorage 本地存储，无需后端 / 无需登录
- **当前版本**：v1.3

### 2.2 💉 注射管理

#### 用药提醒设置

| 字段 | 选项 | 说明 |
|------|------|------|
| 用药频率 | 每天一次 / 每周一次 / 每两周一次 | 选"每天一次"时隐藏注射日 |
| 注射日 | 周一 ~ 周日 | 仅每周/每两周模式显示 |
| 提醒时间 | HH:MM | 默认 08:00 |
| 选择药品 | 7种GLP-1药物 | 见药品库 |
| 剂量 (mg) | 0.25 ~ 15.0 共18档 | 下拉选择，默认 0.25 |

#### 注射部位选择（10个区域）

```
腹部 6 区：
  腹部左上 · 腹部左中 · 腹部右上 · 腹部右中 · 腹部左下 · 腹部右下

四肢 4 区：
  左大腿 · 右大腿 · 左上臂 · 右上臂
```

- 可视化区域选择，点击高亮
- 上次使用的部位黄色标记
- 首页自动推荐下一个轮换部位

#### 手动记录注射

| 字段 | 说明 |
|------|------|
| 注射日期 | 日期选择器，默认当天 |
| 药品 | 下拉选择 |
| 剂量 (mg) | 下拉选择，默认 0.5 |
| 注射部位 | 下拉选择，与部位可视化联动 |
| 备注 | 选填 |

#### 注射历史
